# Página de Perfil Pessoal - Aline Barbosa Silva

Projeto criado como parte do curso de Dev. Full Stack Jr. (+praTi & Codifica), com o objetivo de desenvolver uma **página de portfólio pessoal** usando **HTML5 semântico** e **CSS responsivo**.

## ✨ Sobre o projeto

Esta página apresenta:
- Estrutura semântica completa com HTML5
- Layout responsivo usando Flexbox e CSS Grid
- Variáveis CSS, pseudo-classes e pseudo-elementos
- Navegação suave entre as seções
- Design limpo, moderno e fácil de manter

## 🚀 Como rodar o projeto localmente


1. Clone o repositório: `git clone https://github.com/alinebarbosasilva/pagina-perfil-pessoal.git`
2. Navegue até o diretório do projeto: `cd pagina-perfil-pessoal`
3. Abra o arquivo index.html no seu navegador preferido.
